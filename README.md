# 糸鋸の線

左の指で板を送って回し、右の指で刃を挽いて、今日の線に沿って切り進めるゲームです。同じ日は、だれが遊んでも同じ線です。携帯は横向きで、両手で遊びます。

## 遊び方

1. 画面を横向きにして、「切る」を押します。制限時間は75秒です。
2. 左の指で板を刃へ送り、掴み盤のまわりをひねって板を回します。右の指で刃を上下に挽きます。マウスなら、片方ずつ動かすことができます。
3. 刃は、挽いているときだけ進みます。送りが速すぎると、刃がしなったり折れたりします。
4. 22秒を過ぎれば「仕上げ」で早めに確定しても構いません。線を最後まで覆えたら、22秒前でも確定します。時間が来ると、そこまでの切り口で仕上がります。

最高記録と、その日の最高記録は、この端末に保存されます。0点は記録しません。

終了画面の X と LINE のボタンから、いまの得点をそれぞれの投稿画面で共有できます。

## 開き方

ビルドは不要です。フォルダをウェブサーバーで公開するか、手元では次のように開きます。

```bash
python3 -m http.server
```

ブラウザで `http://localhost:8000/` を開いてください。`file://` では動きません。
